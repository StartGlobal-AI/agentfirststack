Gmail MCP: what it does, and when an agent needs its own inbox

A Gmail MCP server connects an AI agent to a person's existing Gmail through OAuth, so it can search, read, label and draft that person's mail. When the agent needs an address of its own, to sign up for services and read verification codes, give it a separate inbox. AgentFirstStack Mail creates one with an API key and no OAuth.

Updated 4 November 2026

What Google's Gmail MCP server does

Google hosts a Gmail MCP server at https://gmailmcp.googleapis.com/mcp/v1. It is part of the Google Workspace Developer Preview Program, so you need to be in that program to use it (Google's MCP reference).

Its tools, as Google lists them:

  • Reading: search_threads, get_thread, get_message, list_labels, list_drafts.
  • Changing: create_draft, label_message, label_thread, unlabel_message, unlabel_thread.

There is no send tool. The agent writes a draft, and the person reviews it and sends it from Gmail. That suits an assistant working inside someone's mailbox.

Setting it up

Google's configuration guide lists these steps:

  1. In a Google Cloud project, enable the Gmail API and the Gmail MCP API.
  2. Configure the OAuth consent screen and add the gmail.readonly and gmail.compose scopes.
  3. Create a web application OAuth client, select "Use this client for an AI-powered agent", and add your MCP client's redirect URI.
  4. In Claude (Pro, Max, Team or Enterprise), add a custom connector with the server URL, client ID and client secret.

The same guide says to screen prompts and responses for prompt injection, and advises against processing email from unverified sources.

Claude also has its own Gmail connector, which searches the connected account's email and answers questions with citations to the messages it used (Claude's docs). Either way, the agent works in a person's mailbox, with that person's consent.

How the agent's inbox works

# A key: one request, no OAuth and no Google Cloud project
curl -s -X POST https://agentfirststack.com/v1/signup

# The mail MCP server, authenticated with that key
claude mcp add --transport http afs-mail https://mail.agentfirststack.com/mcp \
  --header "Authorization: Bearer $AGENTFIRSTSTACK_API_KEY"

Then the agent calls the tools in order:

  1. create_inbox {"username":"acme-agent"} returns acme-agent@agentfirststack.com. Calling it again returns the same inbox.
  2. The agent enters that address in a signup form.
  3. get_latest_code {"inbox_id":"inb_...","from":"github.com","timeout":60} blocks until the email arrives and returns the code and the verification link.
  4. list_messages, get_message, reply_to_message and send_email cover reading and writing.

Email bodies come back inside UNTRUSTED fences so the agent treats them as data. The mail manual lists all 46 tools and the REST route behind each one.

When to use which

Use the Gmail MCP server when the work is the person's own mail: finding a thread, summarizing what a customer said, labeling, or drafting replies for them to send.

Use an agent inbox when the agent needs its own address:

  • Signing up for a third-party service and reading the verification code.
  • Testing your app's signup, magic-link or password-reset emails end to end.
  • Receiving mail for a project, such as alerts or receipts, without access to the person's mailbox.

You can run both: Gmail MCP for the person's mail, and a separate inbox for whatever the agent signs up for. For a full comparison with a dedicated agent email service, see AgentMail alternative.

Questions

Can the Gmail MCP server send email?

Not with Google's current tool list. It has create_draft, and the person sends the draft from Gmail. The server is in the Workspace Developer Preview Program, so its tools may change.

Do I need a Google Cloud project for Gmail MCP?

Yes, for Google's server. You enable the Gmail API and the Gmail MCP API, set up an OAuth consent screen with the gmail.readonly and gmail.compose scopes, and create an OAuth client marked for an AI-powered agent.

Is there an email MCP server that doesn't need OAuth?

AgentFirstStack Mail takes an API key from one unauthenticated POST, with no email or verification. Add https://mail.agentfirststack.com/mcp with an Authorization: Bearer header. Chat apps that can't hold a key can use OAuth instead.

Should an agent sign up for services with my Gmail address?

It can read the verification email through Gmail MCP, but the new account then belongs to your address and its mail lands in your inbox. A separate inbox keeps the agent's accounts and their mail apart from yours.
