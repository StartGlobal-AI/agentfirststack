AgentFirstStack/Features

What each service includes

Analytics, a tag manager with server-side conversion tracking, email inboxes and session replay. All of it over REST and MCP, with the same key, and free. Comparisons with the tools you may use now.

Analytics instead of GA4, Plausible or DataFast

Tracking
Cookieless by default, single-page and hash routing, custom events and properties (also from HTML attributes), outbound clicks, downloads, forms, 404s, scroll depth, engaged time, Core Web Vitals, site search, UTMs and ad click IDs, consent gating, cross-domain linking
Server events
An events API with a dry run, joined to browser visitors, with user properties
Reports
Stats, timeseries and comparisons, breakdowns by up to three dimensions, custom metrics, channel groups, realtime with a map, engagement rate, average order value, top movers, insights, CSV, one rollup across all your sites
Filters
Wildcards, nested and/or groups, saved segments, new or returning, did or didn't do an event, user properties, timezones
Goals and funnels
Goals that apply to past data, funnels in order or any order, with time windows and revenue per step
People
Visitors, a session list linked to replay, journeys, first touch, retention cohorts, path exploration, six attribution models
Revenue
Stripe in one call with 90 days of history, Polar, Paddle and LemonSqueezy, a payments API, one reporting currency, new and renewal revenue by source, page and campaign
Subscriptions
MRR, ARR and ARPU; new, expansion, contraction and churned MRR; churn and trial conversion, by channel, campaign, country or plan
Ad spend
Import costs per campaign for ROAS, CPA and CAC
Ecommerce
Items in each purchase, with revenue and quantity per product
AI crawlers
Which AI bots read which pages, never counted as visitors
Querying
Read-only SQL with cost limits, and a schema call that lists every event and property
Import and export
History from GA4, Plausible, DataFast or any other tool (their CSV exports or API reports), a check that the numbers match, raw events as NDJSON, CSV or JSON
Sharing
Public dashboards with a password, an expiry and a saved segment
Alerts
Spikes, drops, no data, goals and payments, plus weekly or monthly reports, by webhook, Slack or email
Privacy
Delete a visitor, purge with a dry run, email and phone redaction, path rules, exclusions, a referral-spam filter, Do Not Track and GPC

Tags instead of Google Tag Manager

Workflow
A site scan that finds the tags and tools already there, GTM import (an export or the GTM API), a draft you edit item by item, diffs between versions, a preview log, environments, versions and rollback
Triggers
Pageview, DOM ready, window loaded, consent initialization, clicks, forms, history changes, element visibility, scroll depth, timers, JavaScript errors, video, custom events, trigger groups
Variables
Data layer, URL parts, cookies, element attributes, lookup and regex tables, formatting, about 30 built-ins
Tag options
Priority, scheduling, sequencing, firing limits, consent per tag
Browser tags
GA4, Google Ads, Meta, TikTok, Snap, image pixels, custom HTML on verified domains
Conversion APIs
GA4, Google Ads, Meta, TikTok, LinkedIn, Pinterest, Reddit, Snap, X and webhooks, each counted once with the browser pixel
Routing
Per-platform conditions and parameter rules, test sends
Consent and identity
Consent Mode v2, TCF v2, hashed user data, cross-domain linking, a lookup store for values like margin by SKU
Monitoring
An event and delivery log, tag-fire stats, page coverage, retries and a circuit breaker

Mail instead of AgentMail or a Gmail account

Inboxes
Instant inboxes on our domain or yours, plus-address tags, labels, usage limits you can read
Waiting
Wait for an email and get the verification code or link back, from authenticated senders only
Reading
Threads, search, raw email, attachments and their text, calendar invites, replies without the quoted history
Sending
Send, reply and forward, safe to retry, scheduled sending, delivery status per recipient
Safety
Inboxes on the shared domain reply only to people who wrote first; allow and block lists
Domains
Custom domains with DNS checks, send-only domains, a zone file to import
Forwarding
Each email, or a daily digest, to the people who claimed the project
Events
Signed webhooks, and an event feed an agent can poll without a public URL
Checks
A deliverability report for any message: SPF, DKIM and DMARC

Replay instead of Hotjar or Clarity

Recording
Text and inputs masked in the browser by default, selectors to unmask, mask or block, sampling
Consent
Consent only where the law asks (EEA, UK, Switzerland), Google Consent Mode, TCF v2, Do Not Track and GPC, IP exclusion
Sessions
Search, readable transcripts, summaries across many sessions, raw events, exports, a share-link player and clips
Signals
Rage, dead and error clicks, quick backs, excessive scrolling, JavaScript and console errors, failed requests, a frustration score
Analysis
Tags and identify, saved segments, trends, funnel drop-offs, events defined after the fact
Heatmaps
Click, scroll and attention maps by element or zone, comparisons, conversion share, PNG images
Surveys
Popovers, embedded surveys and a feedback tab: NPS, CSAT, CES, product-market fit and text, triggered on exit intent or after a rage click, each answer linked to its session
Workflow
Notes, labels, stars, signed webhooks, signals sent on to analytics and your tag container
Privacy
Delete or look up one visitor's data, recordings kept 14 days
